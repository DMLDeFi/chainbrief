# Local music

Drop audio files here (`.mp3`, `.m4a`, `.ogg`, `.wav`) to hear them in the game
instead of the built-in generated soundtrack. They play in alphabetical order and
loop. Choose the source under **Settings → Music**.

Files in this folder are **gitignored** and never committed or deployed from the
repository. Only use tracks you have the rights to share if you host the game
publicly — the generated soundtrack is original and safe to publish.
